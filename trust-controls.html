Data Access, Logging, Password Security

Data Access
JupiterOne encrypts all data at rest and in transit.
JupiterOne implements role-based access control (RBAC) on all data, ensuring that employees only have access to the data they need to perform their jobs.
JupiterOne conducts regular data access reviews to ensure that employees only have access to the data they need to perform their jobs.
Access is removed for terminated employees within 24 hours.

Logging
JupiterOne has added multiple logging tools to track the company's activity, endpoint, and infrastructure.
JupiterOne retains logs for a period of time in accordance with regulatory requirements.
JupiterOne generates alerts on changes and events such as log tampering.

Password Security
JupiterOne requires employees to use strong passwords and to change their passwords regularly.
JupiterOne implements password lockout policies to prevent brute-force attacks.
JupiterOne uses multi-factor authentication (MFA) for remote network access and API access.

App Security

Code Analysis
All code runs through automated testing and static code analysis and receives approval from one or more distinct team members.
All updates are required to pass automated testing before deployment to staging and production.

Credential Management
All infrastructure secrets are stored in AWS Key Management Services.
JupiterOne requires MFA for accessing sensitive systems and data.

Software Development Lifecycle
Fully implemented SDLC includes version control, continuous integration, automated lint, end-to-end testing, and segregation of duties.

Vulnerability and Patch Management
Uses Google Cloud Run and GitHub's Dependabot to scan for vulnerabilities.
High-risk security patches applied and verified at least monthly.

Web Application Firewall
Firewall setup on GCP manages ingress/egress traffic and workstations via Palo Alto's Global Protect.
The WAF is monitored 24/7 and updated as needed.
