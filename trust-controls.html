Data Access
JupiterOne encrypts all data at rest and in transit.
JupiterOne implements role-based access control (RBAC) on all data, ensuring that employees only have access to the data they need to perform their jobs.
JupiterOne conducts regular data access reviews to ensure that employees only have access to the data they need to perform their jobs.
Access is removed for terminated employees within 24 hours.

Logging
JupiterOne has added multiple logging tools to track the company's activity, endpoint, and infrastructure.
JupiterOne retains logs for a period of time in accordance with regulatory requirements.
JupiterOne generates alerts on changes and events such as log tampering.

Password Security
JupiterOne requires employees to use strong passwords and to change their passwords regularly.
JupiterOne implements password lockout policies to prevent brute-force attacks.
JupiterOne uses multi-factor authentication (MFA) for remote network access and API access.

Code Analysis
All codes run through automated testing and static code analysis and receive approval from one or more distinct team members.
All updates are required to pass automated testing before they can be deployed to staging and, eventually, production.

Credential Management
All infrastructure secrets are stored in AWS Key Management Services.
JupiterOne requires employees to use multi-factor authentication (MFA) when accessing sensitive systems and data.

Software Development Lifecycle
A fully implemented SDLC is in place that includes:
version control,
continuous integration,
automated lint,
end-to-end testing,
segregation of duties.

Vulnerability and Patch Management
A formal vulnerability and patch management process is in place, including the use of Google Cloud Run and GitHub's Dependabot system to scan for network vulnerabilities, infrastructure, and dependencies.
All systems and applications are patched, and high-risk security patches are applied and verified at least monthly on all server platforms.

Web Application Firewall
JupiterOne has a firewall setup on GCP that controls the ingress and egress traffic and also manages the workstation traffic via the Global Protect solution provided by the Firewall (Palo Alto firewall).
The WAF is monitored 24/7 and updated with new rules as needed.

Recovery Time Objective
Recovery Time Objective: <24 Hours

Recovery Point Objective
Recovery Point Objective: <24 Hours

Hosting
Amazon AWS, by default, in USA East.

Asset Management Practices
JupiterOne maintains an inventory of all corporate assets, including hardware, software, and data.
JupiterOne has a process for tracking and controlling access to corporate assets.
JupiterOne has a process for disposing of corporate assets in a secure manner.

Email Protection
JupiterOne has measures in place to safeguard against email-based security threats.
JupiterOne uses a variety of email security measures, including spam filtering, content filtering, and malware scanning.
JupiterOne employees are trained on how to identify and avoid phishing attacks.

Employee Training
JupiterOne has annual security training to enhance staff awareness of security best practices.
JupiterOne employees are also trained on specific security controls, such as password management and multi-factor authentication.

HR Security
JupiterOne's human resources processes prioritize security and compliance.
JupiterOne has a background check policy in place for all new employees before providing access to company IT systems.
JupiterOne has a process for offboarding employees in a secure manner.

Incident Response
A well-defined plan is in place for addressing and mitigating security incidents.

Internal Assessments
JupiterOne has regular internal evaluations to identify and address security vulnerabilities.

Cookies
JupiterOne uses Cookies and similar tracking technologies to track the activity on JupiterOne’s Service and stores certain information to improve the service JupiterOne provides.

Data Breach Notifications
JupiterOne intends to notify customers promptly and ensure that it has as much information as possible to assess the scope of any security breaches accurately.
Measures are taken to minimize the impact of the incident by implementing effective containment strategies.

Employee Privacy Training
All JupiterOne employees must complete security training and acknowledge the employee handbook and code of conduct.

Backups Enabled

Data Erasure
JupiterOne deletes customers’ data after 30 days of the end of the contract.

Encryption-at-rest
All data is encrypted at rest using AES-256 at the object and volume level.

Encryption-in-transit
All data is encrypted in transit using TLS 1.2+.

Physical Security
The AWS Platform manages the physical security of our data center. (AWS Compliance).

Disk Encryption
The workstations used by employees have full-disk encryption for added security.

DNS Filtering
To monitor internet traffic, a network monitoring solution is used. Additionally, solutions are implemented to block any malicious traffic.

Endpoint Detection and Response
SentinelOne is used as a solution that has endpoints connected to it and is installed on all devices.

AWS
JupiterOne uses AWS for its infrastructure, which provides a number of security features, including:
Security groups to control network traffic to and from JupiterOne's resources.
IAM (Identity and Access Management) to manage user permissions and access to resources.
Robust (AWS Compliance).

Anti-DDoS
JupiterOne relies on GCP which offers Google Cloud Armor against such threats.
Google Cloud Armor provides always-on DDoS protection against network or protocol-based volumetric DDoS attacks.
This protection is for applications or services behind load balancers. It can detect and mitigate network attacks to allow only well-formed requests through load-balancing proxies.

BC/DR
JupiterOne has a BC/DR (Business Continuity/Disaster Recovery) plan to ensure that its business can continue operating in the event of a disaster.
The BC/DR plan includes measures to back up data, replicate systems, and failover to alternate sites.

Infrastructure Security
JupiterOne has a team of security experts who are responsible for monitoring and protecting its infrastructure.
JupiterOne uses a variety of security tools and technologies to protect its infrastructure, including:
Firewalls, Intrusion detection and prevention systems (IDS/IPS), Endpoint protection systems and XDR protection, Data encryption, vulnerability scanning and patching.

Separate Production Environment
JupiterOne maintains a separate production environment for its critical systems.
This helps to isolate production systems from development and testing environments and reduces the risk of disruption to production systems.

Subprocessors

Cyber Insurance
JupiterOne maintains an insurance policy that includes coverage for major security incidents.
