Access Control

Data Access

JupiterOne encrypts all data at rest and in transit.

JupiterOne implements role-based access control (RBAC) on all data, ensuring that employees only have access to the data they need to perform their jobs.

JupiterOne conducts regular data access reviews to ensure that employees only have access to the data they need to perform their jobs.

Access is removed for terminated employees within 24 hours.

Logging

JupiterOne has added multiple logging tools to track the company's activity, endpoint, and infrastructure.

JupiterOne retains logs for a period of time in accordance with regulatory requirements.

JupiterOne generates alerts on changes and events such as log tampering.

Password Security

JupiterOne requires employees to use strong passwords and to change their passwords regularly.

JupiterOne implements password lockout policies to prevent brute-force attacks.

JupiterOne uses multi-factor authentication (MFA) for remote network access and API access.

Corporate Security

Asset Management Practices

JupiterOne maintains an inventory of all corporate assets, including hardware, software, and data.

JupiterOne has a process for tracking and controlling access to corporate assets.

JupiterOne has a process for disposing of corporate assets in a secure manner.

Email Protection

JupiterOne uses a variety of email security measures, including spam filtering, content filtering, and malware scanning.

JupiterOne employees are trained on how to identify and avoid phishing attacks.

Employee Training

JupiterOne has annual security training and targeted training on password management and MFA.

HR Security

JupiterOne performs background checks on new hires and securely offboards departing employees.

Incident Response

A well-defined plan is in place for addressing and mitigating security incidents.

Internal Assessments

JupiterOne performs regular internal evaluations for vulnerabilities.

Endpoint Security

Disk Encryption

DNS Filtering

Endpoint Detection and Response

App Security
